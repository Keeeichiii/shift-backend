Установка и запуск (Docker)

Папка shift: образ shift-app.tar, каталог docker/ с Compose. Текстовая инструкция: INSTALL.txt. Эта страница открывается в браузере на Windows, macOS и Linux.

Состав папки

  • shift-app.tar — сохранённый образ приложения (загрузка через docker load).
  • docker/compose.image.yaml — запуск образа shift-backend:local и PostGIS.
  • INSTALL.txt — те же шаги простым текстом.

Исходников и сборки образа в этот набор не входят — используется готовый shift-app.tar.

1. Установите Docker

ПлатформаСсылка
WindowsDocker Desktop

Запустите Docker и дождитесь состояния «Running».

Windows: подсистема Linux (WSL 2)

Для Docker Desktop на Windows обычно нужен WSL 2. Команды в PowerShell (при необходимости — «Запуск от имени администратора»). После wsl --install или обновления компьютер может попросить перезагрузку — выполните её и продолжайте.

wsl --install
wsl --update
wsl --shutdown
wsl --install -d Ubuntu

Дождитесь установки Ubuntu; при первом запуске задайте пользователя и пароль Linux (это не пароль Windows).

2. Загрузка образа и запуск

На целевом компьютере (путь к папке shift подставьте свой):

# Windows PowerShell
cd C:\shift
docker load -i .\shift-app.tar

cd .\docker
$env:POSTGRES_PASSWORD="замените-на-свой-пароль"
docker compose -f compose.image.yaml up -d
# macOS / Linux
cd ~/shift
docker load -i ./shift-app.tar

cd docker
export POSTGRES_PASSWORD="замените-на-свой-пароль"
docker compose -f compose.image.yaml up -d

Сайт: http://localhost:8090

3. Остановка и логи

cd …/shift/docker
docker compose -f compose.image.yaml down
docker compose -f compose.image.yaml logs app --tail 50

Тома с данными БД сохраняются, пока не выполнить down -v.

Если порт 8090 занят

В docker/compose.image.yaml для сервиса app замените проброс портов на, например, "8091:8090" и откройте http://localhost:8091.
